# Actualización del repositorio — 25 de septiembre de 2026

Esta revisión incorpora la versión local Edge **0.3.26** y Web **1.9.29**,
coincidentes con las versiones del [despliegue documentado del 17 de septiembre](despliegue-inventario-20260917.md).

## Contenido

- Calibración OCIO, filtro temporal, tabla del fabricante y curva de terreno.
- Cuadratura de inventario con márgenes de medición y confirmación de pérdidas persistentes.
- Registro durable de voltajes, exportadores e histórico de litros por máquina.
- Paneles de nivel, inventario, suministro eléctrico y estado del sistema.
- Migraciones SQL 0032–0039, pruebas de regresión, herramientas y documentación.
- Prueba de conteo K24 y persistencia con el relé permanentemente desenergizado.

La configuración incluida selecciona `fm2500_field_20260909`, capacidad de
2.662 L y factor K24 de 90 pulsos/L. Es específica del estanque documentado.
Conserva `ocio_calibration_pending = true`: una instalación nueva requiere el
certificado durable de calibración antes de habilitar esta configuración.
Véase la [calibración final de terreno](calibracion-final-copec-20260909.md).
